(A) Name of your Project: DigiTool / ph-assignment-6

(B) Project Description: DigiTools – Premium Digital Tools Marketplace

DigiTools is a modern and responsive web application that showcases a collection of premium digital products such as AI tools, design templates, stock assets, and automation kits. The platform allows users to explore products, view detailed features, and add items to a cart with a smooth and interactive user experience.

The application is built using React.js with component-based architecture, ensuring scalability and clean code structure. It features dynamic rendering of products from a JSON file, state management for cart functionality, and real-time UI updates (e.g., “Added to Cart” status). Toast notifications are integrated to enhance user feedback during interactions.

(C) Technology that you use:

1. React.js
2. Tailwind CSS
3. JavaScript (ES6+)
4. React Toastify
5. Netlify (Deployment)


(D) Features about your project:

1. Dynamic product listing from JSON data
2. Add to cart functionality with state management
3. Persistent UI state across navigation
4. Toast notifications for user actions
5. Fully responsive design
6. Fast and optimized performance (Vite + Netlify deployment)
